# Experiment rules
Read the root instructions; for quantum work also docs/implementation/QUANTUM-SPEC.md. Label every result as simulator, host prototype, port to the project's own OS or physical-QPU evidence. Make no general claims about quantum acceleration or cloud fallback. AI inference stays on-device without network permission.
`experiments/quantum` is a separate workspace: `cargo +1.90.0 test --manifest-path experiments/quantum/Cargo.toml --locked`, `cargo +1.90.0 clippy --manifest-path experiments/quantum/Cargo.toml --locked --all-targets -- -D warnings`, `cargo +1.90.0 fmt --manifest-path experiments/quantum/Cargo.toml --all -- --check` and `python3 experiments/quantum/verify.py`. The native job gate runs in `ci.yml#qemu-smoke` (`tools/run_qsim_job.py`).
`experiments/quantum/third-party/` is vendored: do not edit it (see `experiments/quantum/THIRD-PARTY.md`). `experiments/ai/model-store-contract` is gated in `component-leaves.yml`.
Manual check: pipe `experiments/quantum/fixtures/bell8.json` into `cargo +1.90.0 run --manifest-path experiments/quantum/Cargo.toml --locked -p qsim-cli`.
