Independent OS research · x86_64 / UEFI

An operating system built from the kernel outward.

Baryon OS is an experimental project developing its own boot chain, Rust kernel, system services, and desktop experience. Its design explores explicit authority and user control over data.

Research software. There is no supported production release. Do not use it for daily work or sensitive production data.

The approach

System research and product design, developed together.

01 / SYSTEM

Independent foundations

The project develops its own x86_64 boot chain and kernel rather than using an existing operating system kernel as its foundation. Processes and services are designed around bounded capabilities.

Read the architecture ↗
02 / EXPERIENCE

Familiar ways to work

The product goal pairs recognisable desktop interactions with explicit access to documents, apps, and connected storage. The interface prototypes explore these flows while native integration continues.

Read the product ambition ↗
03 / EVIDENCE

Claims with a clear boundary

Builds, host tests, QEMU runs, hardware trials, and human evaluation are distinct evidence levels. A browser mockup does not demonstrate kernel enforcement or a working release.

Read the test strategy ↗

Current status

Follow the evidence, not a launch date.

The repository contains an independent boot chain, process and capability infrastructure, services, drivers, an SDK, and native UI work. Integration and acceptance remain in progress. The linked records carry the current scope and open gaps.

Interaction research

Explore the Materiaal browser simulation.

The interactive prototype uses fictitious data to examine documents, permissions, storage and desktop flows. It runs in your browser. It is not Baryon OS running on its own kernel and does not perform real NAS synchronisation, cryptographic verification, package installation, or AI inference.

Use fictional information only. The simulation is not a security boundary or a place to store real data.
