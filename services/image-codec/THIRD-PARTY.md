# Image codec third-party notices

Exact Cargo.lock checksums bind the reviewed, unmodified crates. The published zune-inflate archive omits full licence texts: its immutable repository licence notice and the same project's full MIT terms are preserved below. JPEG is vendored with one local scalar interpolation correction; every other upstream file is byte-identical. The original crate, exact patch and source hashes are in vendor/upstream. No C source from libjpeg is copied: the original Rust correction expresses its mathematical triangle weights and tie rounding, with attribution to libjpeg-turbo 3.1.4.1, commit9217719d3a58633923b096af4c1d50d304768a64, src/jdsample.c:h2v2_fancy_upsample. This local patch is not claimed as upstream accepted.
