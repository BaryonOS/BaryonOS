# Native e08 — historische uitvoering, geen nieuwe replay

De [oorspronkelijke toelichting](README.md.historical.txt),
[runnertekst](native_probe.py.historical.txt), logs, buildmanifesten en receipts
beschrijven de oorspronkelijke e08-proef. De tekstsnapshot is niet uitvoerbaar
en is geen veilige huidige build-/VM-entrypoint.

Native images, firmware, binaries, packages en caches ontbreken bewust uit
deze checkout. Ook `dependency-fetch/*-license-provenance.json` is uitsluitend
een oorspronkelijke lokale verwijzing: deze JSON is **niet gearchiveerd**.
De checkout levert daarvoor geen controleerbaar licentieprovenancebewijs.
Geen bestand bijmaken op basis van de beschrijving.
