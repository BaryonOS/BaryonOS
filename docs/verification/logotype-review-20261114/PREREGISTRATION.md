# Logotype review: pre-registration, 14 November 2026

This file fixes the candidates, criteria, weights and decision rule for the
logotype review **before** any judge has seen the stimuli. It is committed
before the review runs; the commit time is the evidence of that order. The
results will be added in a separate `README.md` in this folder and in
[BRAND.md](../../design/BRAND.md) section 4.

The review is AI judgement by independent reviewer agents. It is not user
testing and not a human design review; scores are judgements, not
measurements.

## Question

Which wordmark sits beside the existing three-node mark in the BaryonOS
lockup, on the surfaces of the selected Orbitaal direction? The mark itself is
not under review. The routes come from [TYPOGRAPHY.md](../../design/TYPOGRAPHY.md)
section 7:

- (a) a wordmark set in Inter, the selected interface face;
- (b) a geometric wordmark in a squared or wide display face, closer to the
  original wordmark;
- (c) keep the current v1 wordmark (Archivo 600/300 at 125 % width) as the
  control.

The original raster wordmark (`ui/design/brand/reference/original-logo.webp`)
stays the reference and the reversible fallback whatever this review decides.

## Stimuli

`STIMULI.sha256` lists the 43 files given to the judges, copied to a folder
outside the repository:

- per code and theme, the full sheet (lockups at 96, 40, 20 and 14 px, an
  "Over BaryonOS" panel beside 15 px Inter interface text, a boot line);
- 1:1 crops of the 40, 20 and 14 px lockups (`*-small-1x.png`);
- 1:1 crops of the panel and boot line (`*-context-1x.png`);
- `reference-original-wordmark.png`, the original wordmark, unblinded, for
  the continuity criterion only.

The "Over BaryonOS" panel is a study surface; the Orbitaal concept itself
shows the mark but no wordmark.

## Judges

Two independent reviewer agents with the same brief. Judge 1 reviews codes
in the order L…S, judge 2 in reverse. Neither may open repository files,
run scripts or see the other's result. Each reports whether it recognises any
face.

## Criteria and weights

Each judge scores every code 1–10 per criterion, considering both themes.

| Criterion | Weight | Question |
|---|---:|---|
| L. Small-size legibility | 30 | Do 20 px and 14 px read cleanly, with "Baryon" and "OS" clearly separate words? |
| F. Fit with the mark | 25 | Do weight, stroke contrast and proportion sit with the mark's bonds and nodes? |
| C. Continuity | 15 | Does it keep the recognisable character of the original wordmark? |
| H. Harmony with the interface | 15 | Does it belong beside the 15 px Inter interface text in the panel? |
| D. Distinct character | 15 | Is it ownable rather than a default system-font label? |

Weighted total (of 100) = Σ score × weight / 10. Per code and per criterion,
the two judges' scores are averaged.

## Decision rule

Let **B** be the code with the highest mean total, and **A** the highest-total
route-(a) code.

1. A code with a mean L of 5 or lower cannot be selected.
2. **A is selected** if all three hold: total(B) − total(A) < 3.0;
   L(A) ≥ L(B) − 0.5; F(A) ≥ F(B) − 0.5.
3. Otherwise **B is selected**. If B is archivo-v1, the v1 wordmark stays.
4. Equal totals are separated by the higher L, then the higher F.
5. If the judges' top codes differ, both are reported; the rule applies to
   the means unchanged.

Why route (a) gets a margin: Inter 600 already exists as native atlas records
(15 px and 22 px, [TYPOGRAPHY.md](../../design/TYPOGRAPHY.md) section 8), so
small native lockups can be drawn from the atlas, and the brand system keeps
one typeface. Route (b) needs an outlined or pre-rendered wordmark asset for
every native size. This is a cost judgement by the lead, not a stated
preference of the project owner, and the project owner can redirect the
outcome.

## Known limits, stated in advance

- Three of the seven candidates are route (a) and three are route (b); more
  variants per route give that route more chances to produce the top code.
- Judges may recognise Inter, and archivo-v1 is the asset already in this
  repository.
- Two AI judges are a small panel; their agreement is reported, not tested
  statistically.
