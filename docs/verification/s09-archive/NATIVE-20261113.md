The archive moves between the volume service and a scoped archive range on the same disposable QEMU test image. This is not S09 acceptance; the criterion stays open.

**Review fixes in this run.** An AI review found the issues below; it is not an independent human audit.
- **`ARCHIVE_ESCAPE`** now counts block objects, nodes and per-process handles, because no handle enumeration exists. The earlier per-handle probes could never fire.
- **Denial counting.** Calls on the portal's own archive object are no longer counted as app device denials. Run 3 logged 26, 7 and 9 denials, inflated by collect polls; run 4 logs 6 in every archive stage.
- **Archive range.** It ends at sector 2040, below the image end, so the portal's past-the-end probe is refused by the capability scope and not by the device size.
- **Restore and corrupt** share one verify-then-restore flow.
- **Oracle.** Export compares the created and modified times; restore expects only referenced collections.
