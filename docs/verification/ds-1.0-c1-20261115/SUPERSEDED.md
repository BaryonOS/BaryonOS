# Superseded permission model

This record verifies the permission model of the project-owner decision of
14 November 2026 (ongoing permissions: "Toestaan tot afsluiten", "Altijd
toestaan", "Weigeren"; single actions: "Eenmalig toestaan", "Altijd
toestaan", "Weigeren"). A project-owner decision of 15 November 2026 replaced
that model with two primary choices, "Toestaan" and "Weigeren", and an
optional remember control that is off by default and applies to both
choices. The new model is researched and verified in task UX-C before it is
adopted.

The contract test, findings and renders in this directory are evidence for
the 14 November model only. They are not evidence for the 15 November model
and must not be cited for it. The record remains valid as the history of
task UX-D-C1. This file is not listed in `SHA256SUMS`. `SHA256SUMS` is pinned to commit
`2142152e`: `docs/design/DESIGN-SYSTEM.md` changes after this record (for
example the section 11.1 note of 15 November 2026), so check the hashes in an
export of that commit (`git archive 2142152e`), not against the live tree.
