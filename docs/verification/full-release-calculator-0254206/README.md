Component `0254206f9b44c75499cf55a9c3716fdb363372ce` heeft begrensd akkoord na onafhankelijke bron-, math-, ELF- en IPC-review. Zeventien bestaande hosttests en vier extra echte Engine/INP1/SUR1-tegenproeven slagen. De afzonderlijke exacte Fraction-oracle controleert 26.424 gevallen plus 48 foutgrenzen. De scalar W^X-ELF is daadwerkelijk geïnspecteerd. De contractnit over startupwoord 0 is bij integratie hersteld: dit is bootmodus, de echte ABI wordt met een syscall gecontroleerd.

Geen native GUI of meerapp-proef uitgevoerd. Launcher, eigen grants, echte focus-/rendererwissels en QMP-bediening blijven verplichte integratie en FR-A08 blijft open. Dit is een zelfstandige algemene decimalengine, geen hardcoded rekenresultaat. De kortstondige omgevingsuitval is hersteld; vier onderbroken hosttegenproeven zijn daarna opnieuw met vastgelegde exitstatus 0 uitgevoerd.
