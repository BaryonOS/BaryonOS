The approach

System research and product design, developed together.

01 / SYSTEM

Independent foundations

The project develops its own x86_64 boot chain and kernel rather than using an existing operating system kernel as its foundation. Processes and services are designed around bounded capabilities.

Read the architecture ↗
02 / EXPERIENCE

Familiar ways to work

The product goal pairs recognisable desktop interactions with explicit access to documents, apps and connected storage. Native integration is still in progress.

Read the product ambition ↗
03 / EVIDENCE

Claims with a clear boundary

Builds, host tests, QEMU runs, hardware trials and human evaluation are distinct evidence levels. The public records state what each result establishes.

Current status

Follow the evidence, not a launch date.

The repository contains an independent boot chain, process and capability infrastructure, services, drivers, an SDK, and native UI work. Integration and acceptance remain in progress. The linked records carry the current scope and open gaps.
