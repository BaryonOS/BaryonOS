What is local AI meant to do?

The product direction treats AI as an optional tool for explicitly selected work, such as clarifying, summarizing, comparing or translating material. Normal editing must remain useful without AI. A model output does not create a permission or authorize a system action.

Can inference use the cloud?

No. System AI inference is required to run on the user's device without inference network permission, NAS fallback or silent provider request. Model download is a separate, explicitly authorized process that must not receive document context, history, indexes or content keys.

What is the first experiment?

The current proposal evaluates a pinned small model and a Rust engine candidate under bounded memory, context, cancellation and numeric requirements. The first native tasks are deliberately narrow. Model provenance, tokenizer/configuration binding, answer quality, latency and resource behavior still require measurement.

What has not been established?

A parser or host model experiment is not a useful native assistant. The roadmap still requires real local inference, bounded selected context, denial of upload routes, graceful insufficient-resource behavior and an OS that remains responsive. No general quality, language or hardware-acceleration claim follows from the proposal.
