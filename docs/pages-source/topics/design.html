What should the desktop feel like?

The intended desktop keeps familiar actions: start an app, search, arrange windows, find a file and change settings. Orbit is the planned dock, with the Zenit launcher and Signaal search. The Orbit-inspired artwork on this website conveys the project's visual direction; it is not a screenshot of a finished OS.

What is Materiaal?

Materiaal is the model for documents, collections, history and access rights. An app is a tool for a permitted task, rather than the owner of every file it can reach. The intended everyday path is to find a document, grant one app limited access, save a revision, and later reopen it with another tool. This model belongs in a familiar Files app and permission dialogs, not in a mandatory unfamiliar home screen.

What makes the design usable and accessible?

Keyboard operation, readable scaling, clear focus, understandable permission language and reduced motion are design requirements. The native desktop, full permission enforcement and independent usability results still require further integration and testing. See progress and evidence before interpreting a design or prototype as a working feature.
