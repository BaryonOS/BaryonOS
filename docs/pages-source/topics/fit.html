Who is the project useful for today?

Baryon OS is useful today for people who want to follow or contribute to operating-system research, inspect an independently developed Rust kernel, or run bounded experiments in QEMU. The repository documents design decisions, source-bound evidence and open limitations in public.

Who should wait?

Anyone looking for a daily-use desktop, a supported installer, guaranteed application compatibility or protection for sensitive production data should wait. There is no supported release, physical support matrix, maintenance commitment or complete end-to-end product acceptance. A visible desktop or passing subsystem test does not change that boundary.

What is the intended future user experience?

The product goal is a familiar, polished desktop with local accounts, understandable app permissions, reliable storage, normal internet access and optional encrypted synchronization to explicitly paired storage. Material keeps documents and their access rights independent from any one app. Local AI is intended to work on-device. These are product requirements under active development, not promises that every function already works.

How can a decision be made responsibly?

  1. Read Status for the current readiness boundary.
  2. Review planned capabilities for the intended product scope.
  3. Check hardware and release readiness for what is not supported.
  4. If the research scope still fits, use the isolated QEMU route or choose a contribution path.
