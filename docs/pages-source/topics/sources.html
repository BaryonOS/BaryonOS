Which source is authoritative?

The versioned repository is authoritative for current product contracts, implementation, progress and evidence. The README introduces the project; PROJECT-STATE records the current checkpoint; PROGRESS defines formal acceptance; FULL-TEST-RELEASE preserves the binding product matrix.

What is this website for?

This website is a visitor-oriented reading layer. It groups common questions and links to the relevant source. It deliberately avoids copying full technical specifications or maintaining a second progress register. If a website summary and a newer repository contract differ, the repository contract prevails.

What role does the GitHub wiki have?

The wiki provides a navigable English introduction and inspired this Docs topic map. It identifies its own source baseline and is not automatically synchronized with every repository change. Current status, commands and acceptance must therefore be checked in the repository.

How can a claim be verified?

Follow the link to the contract or evidence, check its source version and distinguish design, implementation and executed verification. External standards and research can support a design choice but do not establish that Baryon OS implemented or accepted it.
