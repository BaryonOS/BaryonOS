Can Baryon OS be installed on a personal device?

No supported installation on a physical PC or phone is available. The documented route is an isolated QEMU virtual machine for development and testing. It is not a daily-use release or an installer.

How can a development build be started?

First follow the current development guide for the pinned toolchain, firmware and host setup. From a repository checkout, run the basic checks in order:

  1. python3 -B tools/preflight.py --strict
  2. python3 -B tools/build.py
  3. python3 -B tools/run.py --smoke

Use only disposable virtual images, never a real host disk. The selected development profile and its documented output determine whether the smoke test passed. Preflight checks tools; compilation checks a build; neither alone proves runtime behaviour.

What does the smoke test show?

A passing smoke run establishes a bounded native path in the recorded QEMU configuration. It does not establish a complete desktop, supported hardware, safe personal-data use or release acceptance. Consult roadmap and evidence before interpreting a result.
