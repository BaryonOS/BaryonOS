Terms used in this guide

These definitions are reading aids. The linked project contracts give each term its precise technical meaning.

Kernel
The core of the operating system. It manages memory, processor time and access to shared resources.
Capability
A kernel-checked right to act on a particular resource.
IPC
Interprocess communication: messages or requests crossing process boundaries.
Ring 3
The x86 user privilege level for isolated processes outside the kernel.
UEFI
The firmware interface used by the project's loader.
OVMF
UEFI firmware used for the project's QEMU virtual machines.
QEMU
The emulator and virtual-machine environment for scoped guest tests.
Native
Running under the Baryon OS kernel, rather than on the development host.
Host prototype
A test or implementation running on the development computer's OS; it does not establish native integration.
NAS
Network-attached storage. Hosting encrypted data does not automatically grant the administrator a content key.
Security Floor
Core protections that a privacy preference must not disable.
ISA
Instruction-set architecture: the processor instruction model targeted by compiled code.
QPU
Quantum processing unit. Software simulator results are a different evidence category.

For how these terms fit together, start with architecture, then read privacy and security and progress and evidence.
