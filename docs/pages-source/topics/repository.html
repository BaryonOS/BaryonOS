Where is the native system?

  1. boot/UEFI loader and the handoff into the project kernel.
  2. kernel/ and crates/Privileged implementation and reusable no-std contracts.
  3. drivers/ and services/Device paths and bounded system services; some host prototypes are separately labelled.
  4. sdk/ and userspace/Application-facing interfaces, examples and ring-3 probes.
  5. ui/Native UI, the design system and separately labelled browser prototypes.

Where are tests and research?

tests/ and tools/ contain host tests, build/run harnesses and evidence tooling. experiments/ holds AI and quantum research. Folder presence alone does not establish native integration.

Where are decisions and evidence?

docs/ contains current contracts, implementation specifications, decisions, project state, progress and source-bound verification. Begin with the README and current project state before following a subsystem document.
