What is Baryon OS?

Baryon OS is experimental research into an independent operating system. The project develops its own Rust kernel, system services and desktop experience, beginning with x86_64, UEFI and QEMU. It has no supported production release.

Why “Baryon”?

Baryons are composite particles; protons and neutrons are examples. Their composition is a metaphor for a small kernel, separate services and a distinct user environment forming one system. The name does not imply proven safety, stability or a particular hardware capability.

Why build another operating system?

The design goal is a privacy-respecting European alternative with familiar desktop interactions and useful connected functions. A person should be able to find work, understand where data is stored and see which app can access it. This is a product ambition, not a measured comparison with existing systems.

What makes it independent?

The native boot chain and kernel are developed by the project rather than built on Linux, BSD, XNU, Windows or Android. Independence does not mean that every compiler, firmware interface, emulator or reviewed library is made by the project. A development host and the guest OS have different roles.
