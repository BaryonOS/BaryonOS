# Baryon OS

Baryon OS is an experimental operating-system research project with its own kernel. This wiki explains the ideas and vocabulary; the [repository introduction](https://github.com/simonvanieperen/BaryonOS/blob/main/README.md) defines the project scope.

## Reading this wiki

An explanation of a goal does not establish that it works today. Current implementation and open work belong in [PROJECT-STATE](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROJECT-STATE.md); acceptance belongs in [the release contract](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/FULL-TEST-RELEASE.md) and [the criteria register](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROGRESS.md). Version-bound test results stay in [verification](https://github.com/simonvanieperen/BaryonOS/tree/main/docs/verification).

The wiki maintains no separate status log, roadmap schedule, or acceptance register. Licensing and vulnerability reporting always follow [LICENSE-PLAN](https://github.com/simonvanieperen/BaryonOS/blob/main/LICENSE-PLAN.md) and [SECURITY](https://github.com/simonvanieperen/BaryonOS/blob/main/SECURITY.md).
