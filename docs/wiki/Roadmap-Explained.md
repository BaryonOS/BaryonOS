# Roadmap Explained

The M-numbers name technical stages, not equal fractions of completion or promised delivery dates. The following short reading guide summarizes the [canonical roadmap](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/ROADMAP.md); it records no completion state or acceptance decisions.

| Stage | Meaning | GitHub navigation |
|---|---|---|
| M0 | Prepare reproducible tools, design decisions and a threat model. | [M0 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M0) |
| M1 | Boot the project loader and kernel. | [M1 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M1) |
| M2 | Manage memory and handle processor exceptions. | [M2 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M2) |
| M3 | Separate processes and define the system-call boundary. | [M3 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M3) |
| M4 | Make authority explicit through capabilities and IPC. | [M4 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M4) |
| M5 | Introduce a userspace system service and a virtual-device driver. | [M5 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M5) |
| M6 | Develop persistent storage and update/recovery behavior. | [M6 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M6) |
| M7 | Integrate native UI, input, settings and useful apps. | [M7 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M7) |
| M8 | Develop networking and subject security boundaries to review. | [M8 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M8) |
| M9 | Demonstrate support on one documented physical reference PC. | [M9 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M9) |
| M10 | Explore a second instruction-set architecture. | [M10 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M10) |
| M11 | Prepare a documented experimental community release and maintenance path. | [M11 milestones](https://github.com/simonvanieperen/BaryonOS/milestones?state=all&query=M11) |

The milestone links search GitHub's milestone list; an empty result does not imply a completed or missing product feature. Work can overlap across stages. Follow [PROJECT-STATE](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROJECT-STATE.md) for current execution, [PROGRESS](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROGRESS.md) for the fixed weighted criteria and [FULL-TEST-RELEASE](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/FULL-TEST-RELEASE.md) for binding acceptance. Only those repository sources maintain status and evidence.
