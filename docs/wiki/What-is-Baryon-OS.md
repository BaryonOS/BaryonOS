# What is Baryon OS?

Baryon OS explores an independent operating system: its kernel is developed within the project rather than based on Linux, BSD, or another existing OS kernel. The [project introduction](https://github.com/simonvanieperen/BaryonOS/blob/main/README.md) explains the scope and separates the native system from host prototypes.

“Independent” does not mean every tool or dependency is invented here. Compilers, firmware interfaces, emulators and reviewed libraries support the project; their role and provenance belong in [DEPENDENCIES](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/DEPENDENCIES.md).

The project is experimental. A booting VM, a host prototype, and a maintained daily-use OS represent different evidence levels. Consult [current project state](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROJECT-STATE.md) and [the security policy](https://github.com/simonvanieperen/BaryonOS/blob/main/SECURITY.md) before drawing conclusions about suitability or support.
