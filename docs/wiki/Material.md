# Material

Material (named **Materiaal** in the repository and UI) is the project's model for documents, collections and the rights to use them. Apps are tools operating on permitted data rather than receiving general access simply because they are installed. The [product specification](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/implementation/PRODUCT-SPEC.md) defines the model and its limits.

Material is not a requirement that every session start with a novel document-only home screen. The later desktop decision retains familiar desktop, taskbar, window and search conventions; see [the desktop shell design](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/implementation/DESKTOP-SHELL.md) and the ADR-058 amendment at the top of the product specification.

An interface demonstration does not prove permissions are enforced by the OS. Compare [the native Material app](https://github.com/simonvanieperen/BaryonOS/blob/main/sdk/examples/materiaal/README.md) with [the browser prototype](https://github.com/simonvanieperen/BaryonOS/blob/main/ui/prototype/README.md), and use [current state](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROJECT-STATE.md) for their implementation boundaries.
