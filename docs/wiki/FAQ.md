# FAQ

## Is it Linux?

No. The project develops its own kernel; see [the project scope](https://github.com/simonvanieperen/BaryonOS/blob/main/README.md). Using a Linux development host does not make the guest OS a Linux distribution.

## Can it be installed on a personal computer?

Use the VM development route in [DEVELOPMENT](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/DEVELOPMENT.md). Do not infer an installer, supported daily-use release or physical hardware support from a VM demo. The authoritative limits are in [SECURITY](https://github.com/simonvanieperen/BaryonOS/blob/main/SECURITY.md), [current state](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROJECT-STATE.md) and [release acceptance](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/FULL-TEST-RELEASE.md).

## What works today?

Consult [PROJECT-STATE](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/PROJECT-STATE.md) and its linked [verification records](https://github.com/simonvanieperen/BaryonOS/tree/main/docs/verification). This wiki deliberately keeps no second feature checklist or status log.

## Does local-first mean no internet or external storage?

No. The [privacy contract](https://github.com/simonvanieperen/BaryonOS/blob/main/docs/LOCAL-PRIVACY-CONTRACT.md) defines explicit network authority, paired NAS storage and optional opaque encrypted provider storage, with no silent fallback.

## Does the name imply proven safety or quantum speedup?

No. Read [Why Baryon?](https://github.com/simonvanieperen/BaryonOS/wiki/Why-Baryon), [Security Model](https://github.com/simonvanieperen/BaryonOS/wiki/Security-Model) and [Research Tracks](https://github.com/simonvanieperen/BaryonOS/wiki/Research-Tracks) for the distinct concepts and evidence limits.

## What license applies, and how are security problems reported?

Follow [LICENSE-PLAN](https://github.com/simonvanieperen/BaryonOS/blob/main/LICENSE-PLAN.md) and [SECURITY](https://github.com/simonvanieperen/BaryonOS/blob/main/SECURITY.md). Public source visibility does not itself settle licensing, supported releases or a disclosure channel.
