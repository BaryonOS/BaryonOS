## Scope

`MPL-2.0-FILES.txt` is the explicit register of project-owned software covered by this application of MPL-2.0. It includes selected source files for the loader, kernel, drivers, services, SDK, user processes, UI, tests, development tools, and relevant build/CI configuration.

New project-owned software files added to this scope should include an appropriate MPL notice or `SPDX-License-Identifier: MPL-2.0`.

## What is not automatically covered by MPL-2.0

The presence of a root license does not automatically place every repository file under MPL-2.0. Unless explicitly stated otherwise, the software scope does not automatically include:

- third-party code and vendored dependencies;
- fonts and other third-party assets;
- documentation, research sources, and source copies;
- historical and source-bound evidence files;
- project names, logos, and other brand identity.

Third-party components retain their own terms. See [THIRD-PARTY.md](THIRD-PARTY.md) and the component-specific third-party documentation.

## Contributions

A contribution to an MPL-covered file must be made under terms compatible with MPL-2.0, and the contributor must have sufficient rights to offer it. Reused code or assets require a separate provenance and license review.

## Distribution

Anyone distributing MPL-covered source code or executable forms remains responsible for complying with MPL-2.0 and with the notices required by third-party components actually included in that distribution. A repository license is not a complete release SBOM or distribution approval.
